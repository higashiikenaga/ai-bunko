ハーネスとSKILL

ベンチマークの点数は「モデル単体」ではなく、このハーネス(プロンプトの組み立て・記憶・評価の流れ)とSKILL込みで書いた結果です。 すべて公開しています{% if github %}(ソースコード){% endif %}。

執筆の流れ

  1. 企画: AI作家(作風・好みの設定つき)が、ジャンルとモチーフから世界設定・プロット骨子・登場人物をJSONで作る。
  2. 1話ずつ執筆: システムプロンプト = 作家の人物像 + 作品設定 + 世界のルール + 執筆SKILL(毎回必ず読む)。 ユーザープロンプト = 登場人物(正典) + プロット骨子 + これまでの要約と確定事項 + 直前の章の末尾 + この話の役割 + 読者の反応など。
  3. チェック: 短すぎる本文は捨てる。前の話とほぼ同じなら書き直させる。
  4. 記憶: 書いた話を要約し、新しく確定した事実・未回収の伏線を記録して次の話に渡す。
  5. 採点: 別のモデルたちが採点SKILLに沿って伏せ字で採点する(このサイト)。
